Расширение для [веб-версии MAX](https://web.max.ru/). Работает в Chrome, Opera и Opera GX.

Сохраняйте переписку MAX вместе с фото, видео, документами и голосовыми сообщениями на компьютер. Ниже — отдельная инструкция для каждого браузера.

## Chrome

### Шаг 1. Скачайте расширение и распакуйте файл.

[Скачать Max-Chat-Export-0.4.0.zip](https://github.com/almikerov/max-chat-export/releases/download/v0.4.0/Max-Chat-Export-0.4.0.zip). Найдите файл в «Загрузках», нажмите правой кнопкой мыши и выберите «Извлечь всё…». Оставьте имя папки **Max-Chat-Export-0.4.0**.

<img src="https://raw.githubusercontent.com/almikerov/max-chat-export/main/guide/download-card.png" alt="Схема: скачанный файл и папка Max-Chat-Export-0.4.0 после распаковки" width="760">

### Шаг 2. Откройте страницу расширений.

Вставьте `chrome://extensions` в адресную строку и нажмите Enter. Включите **«Режим разработчика»** справа.

<img src="https://raw.githubusercontent.com/almikerov/max-chat-export/main/guide/chrome-developer-card.png" alt="Страница расширений: переключатель режима разработчика справа" width="760">

### Шаг 3. Установите расширение.

Нажмите **«Загрузить распакованное расширение»** слева и выберите папку **Max-Chat-Export-0.4.0** в «Загрузках».

<img src="https://raw.githubusercontent.com/almikerov/max-chat-export/main/guide/chrome-load-card.png" alt="Кнопка загрузки распакованного расширения слева" width="760">

### Шаг 4. Откройте нужный чат и запустите расширение.

Откройте https://web.max.ru и обновите страницу. Выберите личный или групповой чат. Справа от адреса сайта нажмите **значок пазла**, затем **Max-Chat-Export**. Пазл находится рядом со значком профиля.

<img src="https://raw.githubusercontent.com/almikerov/max-chat-export/main/guide/chrome-menu-card.png" alt="Кнопка расширений в виде пазла справа от адреса сайта" width="760">

### Шаг 5. Выберите, что сохранить.

Отметьте переписку, фото, видео, документы или голосовые. При необходимости выберите даты. Оставьте галочку **HTML**, чтобы потом читать переписку как обычную страницу. Нажмите **«Экспортировать»** и дождитесь окончания. Вкладку MAX не закрывайте.

<img src="https://raw.githubusercontent.com/almikerov/max-chat-export/main/guide/export-card.png" alt="Окно расширения: выбор переписки, вложений и кнопка Экспортировать" width="760">

### Шаг 6. Откройте сохранённую переписку.

В папке **«Загрузки → Max-Chat-Export»** появится файл с названием чата. Нажмите на него правой кнопкой мыши → **«Извлечь всё…»**. В полученной папке откройте **messages.html** двойным щелчком.

<img src="https://raw.githubusercontent.com/almikerov/max-chat-export/main/guide/saved-card.png" alt="Схема: где лежит результат и какой файл открыть для чтения переписки" width="760">
